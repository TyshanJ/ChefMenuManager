
# Chef Menu Manager

## Project Description

Chef Menu Manager is a mobile application developed using React Native and Expo. The application allows a chef to create and manage a digital food menu. It provides an easy way to add, view, edit, delete, search and filter menu items.

The application also displays menu statistics to help the chef keep track of the menu.

## Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage

## Main Features

### Menu Management
- Add new menu items.
- View saved menu items.
- Edit existing menu items.
- Delete menu items.

### Search and Filtering
- Search for dishes using their names.
- Filter dishes by course.
- Filter by Starter, Main Course and Dessert.
- Clear search and filters to display all dishes.

### Menu Statistics
- Display the total number of menu items.
- Calculate the average price of all dishes.
- Count the number of starters.
- Count the number of main courses.
- Count the number of desserts.

### Data Storage
Menu items are stored locally using AsyncStorage so that saved menu information remains available when the application is reopened.

## How to Run the Application

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the dependencies:

   npm install

5. Start the application:

   npx expo start

6. Press `w` to open the application in a web browser.
